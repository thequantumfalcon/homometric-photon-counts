METHOD

The input is the reconstructed rational table for moments zero through 64
of both structures (130 values). Its byte hash is pinned in the rational
node-design file and checked by the exact producer.

Optional mpmath exploration generated rational interpolation nodes using
weighted moment orders 0,1,2,3, with respectively 32,32,31,31 nodes. These
are only proposals. All proof decisions use Python standard-library
Fraction arithmetic; nodes must be distinct and strictly inside (0,3969).

For count k=0,1,2, interpolate exp(-eta*x) at positive double nodes.
The even-derivative Hermite remainder gives a global lower bound. Add
a simple node at zero for the odd-derivative upper bound. Multiplying by
x^k preserves these inequalities for nonnegative x. Integrating the
polynomials uses moments no higher than 64. Multiplying by eta^k/k!
gives the exact Poisson-mixture bin probability bounds. Normalization
gives the fourth bin.

Exact exponential enclosures and probability normalization certify
 E_A[exp(-score)] <= 1-c, E_B[exp(score)] <= 1-c,
where c is a positive rational slightly above 1.6650104427228699e-14.
For independent snapshots the Markov bound on each conditional error
is at most (1-c)^m <= exp(-m*c) <= exp(-3) < 1/20. The last strict
inequality follows from an exact positive Taylor partial sum for exp(3).
No central-limit approximation, Monte Carlo estimate, or asymptotic
normality claim is used.

second replays the serialized score/MGF inequalities. The third uses

the detector producer. It verifies the strongest point only. All reject

conditional on the stated mathematical model and moment reconstruction;
