4. Independent effective-resistance reconstruction of C
-------------------------------------------------------
The package builder uses a path pseudoinverse followed by a rank-one chord
update. The reviewer used a different reconstruction: the effective
resistances of the triangle with its two attached path tails.

For a path with the additional chord (p,p+2), the vertices p,p+1,p+2 form
a unit-resistor triangle. The effective resistance between any distinct
triangle vertices is 2/3. The attached path tails contribute their series
resistances. Thus, for i<j, the resistance R_ij is

  j-i-4/3, if i<=p and j>=p+2;
  j-i-1/3, if i<=p and j=p+1;
  j-i-1/3, if i=p+1 and j>=p+2;
  j-i,     otherwise.

Set R_ji=R_ij and R_ii=0. Let R_i=sum_j R_ij and T=sum_i R_i.
The pseudoinverse reconstructed from these resistances is

  C_ij = [(R_i+R_j)/n - R_ij - T/n^2]/2,
  n=63,

equivalently C=-(1/2)P R P with P=I-11^T/n.

This reconstruction matched every supplied rational matrix entry for
both structures. Independently checked exact identities were

  C=C^T,
  C*1=0,
  L*C=I-11^T/63,
  C_ii+C_jj-2*C_ij=R_ij.

For a connected symmetric graph Laplacian these identities identify C=L^+
uniquely and imply the required nonnegative covariance on the centered
subspace. The traces matched exactly:

  tau_A = 121486/189,
  tau_B = 121570/189.

Every off-diagonal resistance is positive. The normalization K_H=63*C/tau
has trace 63, so covariance v*K_H has average centered coordinate variance
v. These statements were established from the reconstructed graph and
exact matrices, rather than accepted solely from JSON check flags.
