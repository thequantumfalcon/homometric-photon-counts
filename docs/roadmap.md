# Research roadmap

| Open target | Evidence needed to close it |
| --- | --- |
| Complete formal model chain | Gaussian characteristic moments and independent product expansion linking the proved phase geometry to intensity moments; formal binding to archived coordinates; a joint phase/count interpretation of the constructed marginal mixtures; binding numerical certificates to the decision theorem |
| Quantitative root stability | A certified full parameter rectangle preserving all four simple roots, including the compact gain interval |
| Global parameter root count | Exclusion of additional roots across all claimed phase widths/backgrounds, not a finite scan |
| Optimal testing and design | Bounds for the exact observation/risk criterion and certified exclusion of competing designs; pooled bins do not automatically bound full counts |
| Historical priority | Theorem-level comparison against the outstanding primary texts, with exact hypotheses and conclusions |
| Physical validation | Calibrated geometry, phase motion and detector measurements, dependence checks, and a feasible acquisition analysis |
| Broader formal portability | A separately validated Linux/macOS toolchain and dependency build; the supplied replay targets the retained pinned Windows environment |

The current reference four-root count is settled within its analytic/computational assumptions. The local stability theorem and fixed-bin necessary count narrow separate gaps. The measurable-mixture extension derives the factorial tower identity for the constructed marginal count laws. The geometry extension proves concrete phase harmonics, the separating phase invariant, and parameter substitution. The Gaussian intensity-moment derivation remains open in Lean. Repository polish, licensing, CI, and artifact integrity support inspection but cannot replace missing mathematical or experimental evidence.
